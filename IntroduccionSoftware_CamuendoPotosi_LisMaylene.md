# 1DAMP_CamuendoPotosi_LisMaylene

**¿Qué es un programa informático?**

Un programa informático es un conjunto de instrucciones ordenadas que se le dan a un ordenador para que haga una tarea concreta, es decir, secuencia de órdenes que le indican a una computadora qué hacer.

**Diferencia entre código fuente, código objeto y código ejecutable.**

- *Código fuente:* Es lo que escribimos nosotros, por tanto, son las líneas de texto que un programador teclea y está redactado en un lenguaje de programación como Python, Java o C++ y que podemos entender y aprender.
- *Código objeto:* Como el ordenador no entiende el lenguaje humano y solo entiende de electricidad ceros y unos. Un programa especial llamado "compilador" traduce el código fuente a código binario, 0 y 1. A ese resultado intermedio, que ya está casi listo pero que todavía no funciona por sí solo, se le llama código objeto.
- *Código ejecutable*: Es el archivo final, el que ya está totalmente terminado y empaquetado. Entonces, cuando el código objeto se junta con otras librerías necesarias del sistema, gracias a un programa llamado enlazador o linker, se crea el archivo final. En Windows, por ejemplo, es el típico archivo que termina en .exe.

**Etapas del desarrollo del software.**

- *Análisis:* Lo primero es enterarse de qué hace falta y qué es necesario, por tanto, hableremos con el cliente (o pensar tú mismo) para saber exactamente qué problemas tiene que resolver el programa y qué funciones va a necesitar.
- *Diseño:* Antes de programar, se hace el "plano" de la aplicación y aquí se decidiremos cómo va a ser la interfaz, es decir, las pantallas que verá el usuario, cómo se van a organizar los datos y qué estructura tendrá todo.
- *Codificación:* En esta fase los programadores por fin se ponen a escribir el código fuente en el lenguaje de programación elegido y siguiendo el diseño que se hizo en el paso anterior.
- *Pruebas:* Como es normal cometer fallos y por eso se produzcan bugs, en esta etapa se usa el programa de mil maneras distintas para ver si se rompe, si falla algo o si va lento, y así poder corregir los errores.
- *Mantenimiento:* Finalmente, una vez que el programa ya se está usando, esta fase dura para siempre, por tanto, sirve para corregir fallos nuevos que vayan saliendo, actualizar el programa para que funcione en móviles u ordenadores más modernos, o añadirle nuevas mejoras.
